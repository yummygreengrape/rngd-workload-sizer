카드당 128(총 conc 1,024)을 두 번 시도해 두 번 다 실패했다.

확인해야 오진을 피한다. 과거 데이터는 최대 동시성이 512 라 오염되지 않았다.

## 이번 세션에서 내가 틀린 것

1. **"서버가 1024 커넥션을 못 받는다"** — 클라만 ulimit 올리고 서버는 안 올린 채
   재시도해서, fd 오류가 사라진 걸 보고 서버 한계로 오독했다. 고칠 수 있는 설정이다.
2. **`S4kv` 의 TTFT p50 을 승인 상한 증거로 쓰라고 했다** — 근거 없이 말했다.
   `peak_running` 이 직접 측정값이고 창에 덜 민감하다.
3. **효율 계산에 규약이 섞였다** — 기동 A 만 180~270초, B·C 는 전체 창이었다.
   통일하니 범위가 76.8~88.7 에서 **74.7~91.2** 로 넓어졌다.
4. **미달률을 낼 때 2장 run 을 섞었다** — `concurrency==32` 로만 걸러 S3x2(2장, 카드당16)가
   들어갔다. 카드 수로 걸러야 한다.
