## 읽는 규칙 하나

**고부하 측정값은 소수점까지 믿지 마십시오.** 같은 조건이 서버 기동마다 최대 22% 흔들립니다
([09-session-4-log.md](09-session-4-log.md)). 저부하는 0.04% 로 재현되므로 측정 하네스의
문제가 아니라 **읽는 방법의 문제**입니다. 고부하 셀은 **방향만 취하고 크기는 반복 횟수·폭과
함께 범위로** 읽습니다.
