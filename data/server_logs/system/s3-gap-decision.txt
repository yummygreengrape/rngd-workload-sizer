# 2장 재측정 판단 기준 — **데이터를 보기 전에 정함**

## 상황

서버 기동 → run 시작 간격이 구성마다 갈렸다.

    1장  30초 (기준선)     2장  12초     4장·8장  30초로 통제

하강이 열 때문이라면 run 시작 시점의 카드 상태가 다르다는 뜻이다.
2장은 카드 확장 곡선에서 1장과 4장 사이를 메우는 **유일한 점**이라,
이상치로 빼면 하필 그 자리에 구멍이 난다.

## 재는 것

두 run 의 **run 시작 시점 카드 온도** (`s3-temp-s3_x1.txt` · `s3-temp-s3_x2.txt`).
측정을 안 건드리고 로그 파일 두 개만 본다.

## 판단 기준 (보기 전에 확정)

    2°C 미만    → 무시. 2장 그대로 쓴다. 간격 통제는 불필요했던 것으로 기록
    2~5°C       → 애매. 재측정은 §1·§2·§3 이 끝나고 시간이 남을 때만
    5°C 이상    → 재측정 (16분). §4 를 버린다

## 이 숫자를 고른 근거

세션 2 에서 **npu0(53.93°C)과 npu6(49.70°C)이 같은 부하에서 4.2°C 차이**였는데
같은 조건 측정값이 **0.36% 차이**였다 — 산포(0.92%) 안이다.
**4.2°C 가 성능을 안 움직였다.** 그래서 그보다 작은 차이는 무시한다.

다만 그 비교는 **부하 중 정상상태의 카드 간 차이**이고, 여기서 보는 것은
**시작 시점의 온도 차이**다. 기전이 다를 수 있어 5°C 에 재측정 선을 둔다.

## 예상

**2°C 미만이 나올 것으로 본다.** 18초 차이로 카드가 그만큼 식지 않는다.
그러면 간격 통제는 안 해도 됐던 것이고, 그 사실 자체를 기록한다 —
**통제가 필요했는지 여부도 데이터로 답할 수 있다.**

## 결과 (22:14 확인, 기준 기록 후)

    1장 (간격 30초)  run 시작 +9초   npu0  47.92°C / 174W
    2장 (간격 12초)  run 시작 +10초  npu0  48.17°C / 155W
                                          차이 0.25°C

**2°C 미만 → 무시. 2장을 그대로 쓴다. 재측정하지 않는다.**

예상대로였다. 18초 차이로 카드가 그만큼 식지 않는다.
**간격 통제(4·8장 30초)는 안 해도 됐던 것이고, 그 사실을 데이터로 답했다.**
다만 통제 자체는 비용이 0 이었으므로 그대로 둔다 — 다음 세션에서 다른 변수를
볼 때 이 축이 이미 고정돼 있으면 편하다.

## 한계

두 샘플 모두 **run 시작 9~10초 뒤**라 부하가 이미 걸린 상태다.
온도 수집이 run 을 띄운 뒤에 시작되므로 **진짜 시작 시점 온도는 못 봤다.**
말할 수 있는 것은 **"run 시작 후 같은 경과 시점에 두 구성의 카드 상태가
0.25°C 안에서 같았다"** 까지다. 그것으로 충분하다 — 간격 차이가 카드 상태에
남아 있었다면 같은 경과 시점에 차이가 보여야 한다.

전력이 174W vs 155W 로 다른 것은 초기 상태가 아니라 **부하 분산 차이**다
(1장은 한 카드에 전부, 2장은 두 카드에 나눔).
